# SlackingOffTimer PRD v0.1（MVP）

## 1. 文档信息
- 版本：v0.1（MVP）
- 产品名称：SlackingOffTimer（摸鱼计时器）
- 目标：以“极简无感”方式，帮助用户自动统计工作时段内的摸鱼时长，并在下班时反馈每日总结。

## 2. 背景与问题
很多用户想知道自己在工作时间内的手机分心情况，但不愿意频繁手动打卡、记录。目标是让用户**一次设置，长期自动统计，低打扰反馈**。

## 3. 产品目标（MVP）
1. 用户首次完成工作制度设置（工作时段、午休时段）。
2. 系统可自动记录“摸鱼会话时长”（Web MVP 用页面活跃会话近似）。
3. 提供“今日摸鱼时长 + 摸鱼占比”。
4. 提供近 7 天趋势数据。

## 4. 目标用户
- 编程新手、效率工具轻度用户、上班族。
- 偏好：操作简单、页面干净、无需频繁维护。

## 5. MVP范围

### 5.1 首次设置
- 上班时间（startTime）
- 下班时间（endTime）
- 午休开始/结束（lunchStart/lunchEnd，可选）
- 工作日（默认周一到周五）

### 5.2 自动计时（Web近似实现）
- 用户在页面点击“开始摸鱼会话”后开始计时。
- 点击“结束会话”或页面失焦（blur）时结束并结算。
- 当前版本作为手机解锁计时的产品验证替代方案。

### 5.3 数据展示
- 今日摸鱼总时长（分钟/小时）
- 今日摸鱼占比（摸鱼时长 ÷ 工作时长）
- 近 7 天趋势列表（日期、时长、占比）

### 5.4 数据存储
- localStorage 存储：
  - 工作制度（schedule）
  - 每日统计（daily stats）

## 6. 非目标（v0.1 不做）
- Android/iOS 原生后台常驻与真实解锁监听
- 云端账号体系与多设备同步
- 团队排行、社交分享
- 精细化应用白名单统计

## 7. 核心口径定义
- 工作窗口：工作日 + [startTime, endTime)，排除午休区间
- 摸鱼时长：有效会话累计分钟数
- 摸鱼占比：`fishMinutes / workMinutes * 100%`
- workMinutes 默认可先取固定值（如 480 分钟），后续迭代改为按用户配置动态计算

## 8. 用户流程
1. 首次打开 -> 设置工作制度并保存
2. 回到首页 -> 开始/结束会话
3. 系统自动累计当天统计
4. 查看今日概览和近 7 天趋势

## 9. 页面结构（MVP）
1. **首页（Today）**
   - 今日摸鱼时长
   - 今日占比
   - 当前状态（待机/计时中）
   - 开始/结束会话按钮

2. **设置区（可放首页）**
   - 工作起止时间
   - 午休时间
   - 保存按钮

3. **趋势区**
   - 最近 7 天统计列表

## 10. 数据结构（建议）
```ts
type WorkSchedule = {
  workDays: number[];
  startTime: string;
  endTime: string;
  lunchStart?: string;
  lunchEnd?: string;
};

type DailyStat = {
  date: string;       // YYYY-MM-DD
  fishMinutes: number;
  workMinutes: number;
};
```

## 11. 成功指标（MVP）
- 首次设置完成率
- 每日有记录用户占比（DAU 中有统计数据的比例）
- 7 日内回访率
- 用户主观反馈：是否“低打扰、好理解”

## 12. 风险与约束
- Web 端无法真实监听手机解锁，不等同原生系统能力。
- localStorage 无法跨设备同步，且用户清缓存会丢数据。

## 13. 迭代路线（v0.2+）
1. 接入 Supabase（云端持久化）
2. 增加下班提醒（Web Push / 邮件）
3. Android 原生版本：解锁自动计时 + 后台稳定策略
4. 更细粒度统计口径（白名单应用、专注时段）

## 14. 验收标准（v0.1）
- 可保存并读取工作制度
- 可创建会话并累计当天摸鱼时长
- 可正确显示摸鱼占比
- 可展示最近 7 天统计
- 页面可在在线开发环境运行（`npm run dev`）
