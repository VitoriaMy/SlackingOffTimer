# SlackingOffTimer 验收清单（MVP）

## A. 首次使用（Onboarding）
- [ ] 首次打开应用仅展示设置页面
- [ ] 可填写上班/下班时间
- [ ] 可填写休息制度（休息开始/结束）
- [ ] 时间校验生效（非法时间不可保存）
- [ ] 保存成功后标记已配置状态

## B. 设置后行为
- [ ] 保存后出现“已生效/可后台运行”的提示
- [ ] Web 降级提示文案准确（说明无法系统级后台常驻）
- [ ] 再次打开默认进入主页面

## C. 主页面
- [ ] 展示今日摸鱼时长
- [ ] 展示今日摸鱼占比
- [ ] 展示当前状态（计时中/待机/非工作时段）
- [ ] 有“查看最近7天趋势”入口
- [ ] 有“修改工作制度”入口

## D. 趋势页面
- [ ] 具备独立路由页面（如 `/trends`）
- [ ] 展示最近7天每日摸鱼时长
- [ ] 展示最近7天每日摸鱼占比
- [ ] 可从趋势页返回主页面

## E. 统计逻辑
- [ ] 在工作窗口内可开始/继续计时
- [ ] 失焦/离开工作窗口停止计时
- [ ] 会话时长正确累计到当天
- [ ] 跨天数据不会写错日期

## F. 存储与稳定性
- [ ] schedule 正确保存和读取
- [ ] daily stats 正确保存和读取
- [ ] 数据损坏时可回退默认值

## G. 文档一致性
- [ ] README 与 PRD 描述一致
- [ ] PRD 与实际功能边界一致（Web降级说明存在）
