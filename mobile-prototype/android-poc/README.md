# Android POC (Foreground Service + Unlock Trigger + Daily Push)

## 验证目标

1. 服务在后台常驻并定时运行计时逻辑
2. 解锁触发开始会话，熄屏触发停止会话
3. 到下班时间后推送“推送：摸鱼小计”，且每天一次

## 运行方式

1. 用 Android Studio 打开目录：`mobile-prototype/android-poc`
2. 使用真机（Android 10+）安装运行
3. 首屏点击“启动后台计时服务”
4. 在系统通知中确认“SlackingOffTimer 运行中”常驻通知

## 建议验证步骤

1. 调整默认下班时间为当前时间后 2~3 分钟（可在 `LocalStore` 默认配置里修改）
2. 锁屏 -> 解锁 -> 亮屏停留 1~2 分钟 -> 熄屏
3. 回到 App 查看“今日摸鱼分钟”是否增长
4. 等待到下班时间后，检查是否收到“推送：摸鱼小计”

## 风险提示

1. 部分厂商系统会强杀后台服务，需要关闭电池优化
2. 解锁广播可靠性受机型影响，需要多机型回归
